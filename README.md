I build **production AI systems** — LangGraph agents, RAG pipelines, multi-step LLM workflows — and I like deciding *what* to build as much as building it.

- 🎓 **MSc Artificial Intelligence & Machine Learning** at the University of Birmingham (Russell Group), graduating Sept 2026
- 🔬 **Active NLP research** on faithfulness evaluation in LLM summarisation, supervised by Dr Mubashir Ali — targeting ACL
- 🚀 **5 production-style AI applications shipped in 12 months**, alongside the MSc
- 💼 **3 years of prior production engineering** (Python / Java) at Kalki Communication Technologies
- 🏆 **2nd Place** — Google AI Playground London (invitation-only, Dec 2025)
- 🎖️ **Birmingham Award holder** — University-accredited recognition for sustained initiative
- 💬 Ask me about: **LangGraph agents · RAG · prompt engineering · production ML · graph-based NLP**
